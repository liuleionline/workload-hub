# 开源前审计

审计日期：2026-08-26

## 当前结论

项目已完成首轮公开整理。版权人确认为 `3_stones`，代码、文档、Logo、图标和公共视觉素材统一采用 `AGPL-3.0-only`。源码测试通过，Go 依赖未发现可达漏洞；原本用于构建的 Go 1.26.5 标准库存在已知漏洞，项目现已要求 1.26.6。

## 已识别并处理

|项目|处理|
|-|-|
|SSH 私钥、known_hosts、内部交接文件|`.gitignore` 排除 `tmp/` 和常见密钥文件|
|生产及迁移数据库|`backup/`、`dist/`、`*.db` 等排除|
|历史二进制、PDF、视频和开发截图|`dist/`、`output/`、`outputs/` 排除|
|真实同事照片|原文件保留在本地但不跟踪；公开克隆使用原创 SVG 默认背景|
|生产域名与 SSH 端口|公开部署样例改用 `workload.example.com`|
|真实员工和项目初始库|不进入仓库；改为匿名 CSV 示例|
|依赖声明不完整|`modernc.org/sqlite` 改为直接依赖并补齐 `go.sum`|
|Go 标准库漏洞|工具链下限锁定为 Go 1.26.6|
|手册宣称 Word 导出但代码未实现|公开手册改为实际支持的 Excel、浏览器 PDF 和图表图片|
|版权与许可证|版权人为 `3_stones`；根目录加入 AGPLv3 标准全文和公共资产授权声明|

## 授权决定

- 版权人：`3_stones`
- 许可证：`AGPL-3.0-only`
- 授权范围：代码、文档、Logo、图标和随仓库分发的公共视觉素材
- 名称与 Logo：不设置独立于项目许可证之外的保留授权条件

## 公开发布前最后操作

1. 首次推送前再次运行密钥扫描；即使密钥被忽略，也不要把现有私钥复制进仓库历史。
2. 确认远程仓库只包含 `git ls-files` 中的公开候选文件，不上传本地忽略目录。
3. 首次推送后确认 GitHub Actions 全部通过。
4. 在 GitHub 开启 Private vulnerability reporting、Dependabot alerts 和分支保护。
5. 若开源整理后需要更新线上版本，再用 Go 1.26.6 单独构建、验收和部署；开源提交本身不触发生产部署。

## 已知技术债

- 测试语句覆盖率约 48.4%，核心业务规则覆盖较多，但部分 HTTP 异常路径和运维流程仍依赖验收清单。
- 迁移采用“建表脚本 + 缺列补齐”，尚未形成按版本递增的迁移目录。
- 密码最低 6 位是现有业务兼容要求，公开部署应使用更强临时密码并考虑后续升级到 Argon2id。
- 单部门是当前产品边界；多部门隔离尚未经过完整权限和统计验证。
- 节假日数据按年度维护，2027 年及以后需更新。
- 阿里云盘同步依赖第三方 CLI，不属于核心应用能力。

## 推荐公开范围

公开：Go 源码、数据库 schema、模板、CSS/JS、Logo、抽象默认背景、匿名示例、通用部署样例、用户手册和测试。

不公开：任何数据库或备份、导入后的名单、真实项目清单、团队照片、开发过程视频/PDF、SSH 文件、生产环境配置、OAuth 配置和现有发布二进制。
