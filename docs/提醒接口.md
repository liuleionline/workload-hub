# 未填报提醒只读接口

此接口供外部任务查询未填报名单，不负责调度或发送邮件。默认关闭，无需网站登录 Cookie。

## 请求及权限

`GET /api/v1/worklog-reminders`

请求头：`Authorization: Bearer <专用随机凭据>`。必须通过 HTTPS 调用。凭据只对本接口有效，不能用于管理员页面、工时明细、导出、修改数据或登录。不要将凭据放进 URL、日志、聊天记录或公开仓库。

只返回员工 `user_id`（系统内部稳定编号，不是工号）和 `name`，不包含邮箱、密码、工时或项目信息。接口不验证员工是否在职；应由管理员及时停用离职账号。

## 填报判断

- 范围与管理员提醒一致：启用的非测试账号。
- 对应填报周有实际工时记录，或有请假记录，即为已提交；0 工时提交、仅请假提交也算已提交。
- 根据系统设置的实际填报窗口计算，不能在调用方硬编码周次或截止时间。
- 窗口固定24小时；开始日休息时提前到最近实际工作日（调休上班日也算）。统计周编号仍为原周五，不随开启日改变。
- 上周六至本周五整周没有工作日：`reason=holiday_week`、`window_open=false`、`should_remind=false`、`missing=[]`，不返回 counts，也不列为漏报。
- `reminder_at` 为实际开启后4小时。开放期间到点前为 `reminder_not_due`，到点一分钟后为 `reminder_time_passed`；均不允许发信。`missing` 仍是即时未填名单，不能脱离 `should_remind` 单独决定发送。
- 窗口关闭：`window_open=false`、`should_remind=false`、`reason=window_closed`、`missing=[]`，不返回 counts。此时 week_end 表示网站当前采用的填报周，可能为上一周；不得用于催填。
- 窗口开放且全部提交：`reason=all_submitted`、`should_remind=false`、`missing=[]`。
- 配置不可读、缺失或无效，以及查询失败时返回 503，绝不当成“全员未填”。

开放窗口的示例（虚构数据）：

```json
{
  "schema_version": 1,
  "checked_at": "2026-11-06T16:00:00+08:00",
  "timezone": "Asia/Shanghai",
  "week_end": "2026-11-06",
  "window_start": "2026-11-06T12:00:00+08:00",
  "window_end": "2026-11-07T12:00:00+08:00",
  "reminder_at": "2026-11-06T16:00:00+08:00",
  "window_open": true,
  "should_remind": true,
  "reason": "missing_submissions",
  "counts": {"eligible": 2, "submitted": 1, "missing": 1},
  "missing": [{"user_id": 7, "name": "示例员工"}]
}
```

响应为 JSON，禁止缓存。401 表示凭据缺失或无效；405 表示非 GET；503 表示接口未启用或暂不可用。任何非 200、网络错误或格式异常都应停止提醒并通知维护者。

## 外部任务建议

每分钟读取；仅在 200、schema_version=1、window_open=true、should_remind=true 时处理 missing。核对 checked_at 足够新，当前时间处于 reminder_at 开始的一分钟内，且仍在 window_start 到 window_end 的左闭右开区间内。错过不自动补发。日历、窗口不可读取或重叠时，停止提醒，不得按“全员未填”处理。

实际提醒前再次读取，确认 user_id 仍在同一 week_end 的 missing 内；按 `week_end + user_id` 去重。发送结果不确定时停止自动重发，交由人工核对。接口只给出即时快照，不能消除查询后员工立即提交的竞争窗口。邮件地址映射和邮件发送权限不由本接口提供。

## 管理凭据

在私有环境生成至少 32 字节的密码学随机值作为凭据；服务端仅保存该凭据 UTF-8 字节的 SHA-256，使用 Base64URL 编码、不带 `=` 填充，配置到 `APP_REMINDER_TOKEN_HASH`。明文凭据只交给指定调用方的安全配置，不使用管理员密码。

修改该环境变量并重启应用即可轮换；清空并重启即可撤销，接口恢复 503。不要写入源码或提交真实配置。示例环境文件只保留空值。
