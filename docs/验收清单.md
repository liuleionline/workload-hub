# 载衡验收清单

## 账号与权限

- [ ] 邮箱登录、首次强制改密、管理员重置密码
- [ ] 系统管理员可增删登录背景，登录页随机取图且对话框保持清晰半透明
- [ ] 登录失败限流、会话过期、停用账号立即失效
- [ ] 三层角色默认权限正确
- [ ] 个人权限允许/禁止覆盖生效并留审计记录
- [ ] 专业负责人不能访问部门分析和修正负荷
- [ ] 只有具有“查看部门看板”权限的用户可以访问月度、季度与年度员工/项目看板
- [ ] 员工周期看板可切换月度、季度或全年，并显示工时、负荷、繁忙周、超负荷周、填报覆盖、项目参与及两类排名
- [ ] 项目周期看板可切换月度、季度或全年，并显示项目总工时、资源占用、参与人数、活跃周、峰值和排名
- [ ] 当前月、季度或年度仅统计到最近统计周，临时“其它”工作不计入项目总工时和项目排名
- [ ] 设计师不能查看项目资源看板

## 项目与填报

- [ ] 普通项目1位专业负责人，超大项目最多2位
- [ ] 执行专业负责人可以填写预估和完成项目
- [ ] 项目负责人允许填写系统外人员姓名
- [ ] 项目阶段支持投标、方案设计、初步设计、施工图设计、工地服务多选
- [ ] 既有项目缺少项目阶段时向对应专业负责人显示待完善提醒
- [ ] 项目简介包含项目地址、项目类别、项目规模、子项组成4个必填项和项目特点可选项
- [ ] 项目总表显示本周原始/有效工时、部门资源占用率、已填工时构成比、参与人数和负责人预估
- [ ] 第6周起只修正满足连续周及同项目配对条件的员工—项目工时，未满足部分保留原始值
- [ ] 项目详情显示全部历史参与人员、工作内容、本周实际/预估、近12周及累计工时
- [ ] 项目详情显示近12周原始/有效工时和部门资源占用率趋势与明细
- [ ] 专业负责人项目页不显示偏差系数、修正工时和部门总量，部门领导按权限可见
- [ ] 周五12:00开放、周六12:00截止，窗口内可修改，窗口外禁止提交
- [ ] 上周项目、工时和承担工作正确带入
- [ ] 第一次参与项目时4项工作内容必填：子项号及名称、建筑面积、结构形式、担任职责
- [ ] 再次选择历史参与项目时自动带出最近工作内容，空白提交仍沿用原内容
- [ ] “其它”不带入下一周但计入统计
- [ ] 个人结束参与和整个项目完成相互独立

## 计算与看板

- [ ] 请假0.5天后可用工时正确变化
- [ ] 节假日和调休工作日正确变化
- [ ] 负荷颜色阈值可配置
- [ ] 连续X周超过Y小时触发报警
- [ ] 部门当前周员工表显示项目数、项目/其它工时、原始负荷、偏差系数和修正负荷
- [ ] 点击员工姓名可按周查看项目、项目阶段、承担工作、实际/预估工时和其它工作明细
- [ ] 员工详情正确区分同项目已配对、仅有实际和仅有预估
- [ ] 收回 dashboard.bias 权限后，部门表、员工详情和趋势数据均不暴露偏差及修正数值
- [ ] 仅使用同员工、同周、同项目且实际与预计同时存在的工时计算偏差系数
- [ ] “其它”、仅有实际和仅有预计的项目均不进入偏差系数分子分母
- [ ] 连续填报5周后，第6周开始按紧邻最近4周有效偏差系数生成修正工时
- [ ] 缺少连续填报周或最近4周任一有效系数时不启用修正
- [ ] 偏差系数、修正工时和修正负荷仅部门领导可见
- [ ] 部门月平均、周峰值和12周趋势口径正确

## 导出与运维

- [ ] 个人明细及全部门月度/季度/年度Excel总表可正常打开
- [ ] 浏览器保存PDF和图表PNG可用
- [ ] 每周六18:00备份、VPS保留3份及阿里云盘异地上传可用
- [ ] 从备份恢复后登录、工时和审计记录完整
- [ ] 网页恢复会先校验备份、生成恢复前保护副本，并强制全部账号重新登录
- [ ] 系统管理员可创建三种业务层级的测试用户，测试用户免首次强制改密且继承对应层级功能
- [ ] 测试用户个人页面可看到自己的测试数据，但部门员工/项目/周期看板及部门总表均不计入测试数据和测试项目
