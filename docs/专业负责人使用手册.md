# 载衡专业负责人使用手册

本手册适用于“专业负责人”。专业负责人除完成设计师的每周实际工时填报、个人看板和个人统计外，还需要负责项目资料维护、项目创建、项目完成/归档，以及所负责项目的下周工时预估。

## 一、首次登录后先做什么

登录入口：请打开系统管理员提供的登录页。
登录账号：院邮箱
初始密码：身份证号后6位



1. 使用初始密码登录后，先修改密码。新密码至少6位。
2. 进入“项目管理”，查看系统中已分配给自己的项目。
3. 对标记为“资料待完善”的项目逐项核对并补充：

   * 项目编号（旧项目填R盘项目编号，新项目填系统平台项目编号）
   * 项目名称（项目全名）
   * 项目简称
   * 项目类型：超大、大、中、小（参照下方项目规模表）
   * 项目阶段：投标、方案设计、初步设计、施工图设计、工地服务，可多选
   * 项目负责人 / 总设计师
   * 开始日期
   * 预计结束日期
   * 专业负责人及执行专业负责人
   * 项目简介：项目地址（必填）、项目类别（必填，如工业/公共建筑/电子/芯片/标准厂房）、项目规模（必填）、子项组成（必填）、项目特点（可选）
4. 保存项目资料。项目负责人 / 总设计师只是项目资料中的姓名，可以填写公司其他员工，不要求其拥有本系统账号。

只有“超大”项目才允许设置两位专业负责人；超大项目也可以只设置一位。设置两位时，应指定其中一位为执行专业负责人。执行专业负责人负责该项目的日常系统操作，包括下周工时预估和项目完成操作。

## 二、每周五完成两类填报

每周五12:00至周六12:00为填报窗口。系统会在窗口开放时提醒登录；窗口内允许反复修改，窗口外不可提交。每周填报包括两部分：

### 1\. 填报本人上周实际工时

进入“工时填报”，填写上次周填报截止点至本次填报截止点之间的实际工作小时数。

* 从第二次填报开始，系统会自动带入上周填写的项目、工时和承担工作，可以直接修改。
* 第一次填写参与某项目时，必须完整填写4项：子项号及子项名称、建筑面积、结构形式、担任职责（独立设计/写明设计部分、校对、审核）。以后再次选择该项目时，系统会自动呈现最近一次内容；除非有新增或变化，无需重复填写。
* 项目工作选择项目名称；临时工作、领导临时指派的工作、工地验收等选择“其它”，并填写具体工作内容。
* “其它”工作会计入本周实际工时和负荷，但不会自动带入下一周的填报项目。
* 如果以后不再参与某项目，可勾选“结束本人参与”。
* 有请假时，按半天为单位填写请假天数，例如1.5天。系统会按请假后的可用工作小时数计算负荷；法定节假日由系统工作日历自动处理。

### 2\. 预估负责项目下周工时

进入“下周预估”，依次选择自己创建或负责的进行中项目，为项目参与人员填写下周预计投入的工时。

* 需要填写参与该项目的设计人员，也包括专业负责人本人。
* 系统会列出当前项目参与人员，也允许从其他员工中增加人员。
* 某员工填写了大于0的预估工时后，系统会自动将其加入项目参与人员。
* 工时可以按半小时填写，必须是0至168小时之间的数字。
* 保存后，系统会汇总员工在各项目中的预估工时，用于计算下周个人和部门负荷。
* 如果项目下周不再需要某人投入，将该人员的预估工时清空后保存。

实际工时由员工本人填报；下周项目工时由相应项目的专业负责人预估。两者不要混填。

系统中的“超大”不是表格中的普通“大型”，而是单独的管理级别。满足下列任意一项时，应选择“超大”：

* 项目面积超过10万平方米；
* 建安投资超过10亿元；
* 项目具有特殊性、复杂性，按管理需要列为超大项目。

只有“超大”项目才允许设置两位专业负责人；超大项目也可以只设置一位。设置两位时，应指定其中一位为执行专业负责人。若项目同时满足普通“大”标准和“超大”条件，按“超大”执行。项目规模判断不确定时，应先与部门领导确认，再保存项目档案。

## 四、新项目创建

有新项目时，进入“项目管理”，点击“新建项目”。创建人默认记录为当前登录的专业负责人。

需要填写：

* 项目编号
* 项目名称（项目全名）
* 项目简称（用于同事口头称呼和看板展示）
* 项目类型
* 项目阶段：从投标、方案设计、初步设计、施工图设计、工地服务中选择，允许多选
* 项目负责人 / 总设计师
* 开始日期
* 预计结束日期
* 专业负责人
* 执行专业负责人
* 项目简介：项目地址、项目类别、项目规模、子项组成为必填；项目特点可选

普通项目设置1位专业负责人；“超大”项目可设置1位或2位，设置2位时指定其中1位为执行专业负责人。创建后应再次打开项目档案，检查负责人、日期、项目类型、项目阶段和项目简称是否准确。

## 五、项目完成与归档

项目彻底完成、下周不再需要安排投入时，在“项目管理”中找到该项目，点击“完成”或“归档”并确认。

* 只有项目创建人、执行专业负责人或被授予相应权限的部门领导可以操作。
* 完成/归档后，项目不再出现在进行中的下周工时预估项目中。
* 历史实际工时、预估记录、参与人员记录和统计报表会保留，不会因为完成或归档而删除。
* 如果项目只是暂时停滞、后续仍可能继续投入，不要提前完成或归档，应继续保留为进行中项目。

## 六、专业负责人可以看到的看板

登录后可查看以下内容，具体权限以系统管理员设置为准：

* 本人当前自然周实际工时、可用工时、负荷率和连续周趋势。
* “项目管理”首先显示自己负责或创建项目的本周原始工时、部门资源占用率、部门已填工时构成比、参与人数和负责人预估。
* 点击项目名称可查看项目资料、全部历史参与人员、员工填写的子项/角色工作内容、本周实际与预估、个人负荷占用、项目投入构成、近12周工时趋势及累计工时。
* 专业负责人项目页只显示原始工时口径，不显示偏差系数、修正工时或修正标记；这些内容仅供具备相应权限的部门领导查看。
* 参与自己负责项目的设计人员当前工作负荷。
* 自己负责项目的下周工时预估汇总。
* 本人月度、季度或年度参与、完成项目清单及统计导出。

专业负责人默认不能查看：

* 其他无关项目的人力占用情况。
* 整个部门的总人力看板和全员月度、季度、年度汇总。
* 员工实际工时与负责人预估之间的偏差系数。
* 按偏差系数修正后的工时和负荷看板。

如果系统管理员为某位专业负责人单独增加或收回权限，实际可见内容以登录后的菜单和页面为准。

## 七、每周检查清单

每周六12:00前确认：

1. 本人上周实际工时已经提交。
2. 请假天数已经填写，且按半天填写。
3. “其它”临时工作已写明具体内容。
4. 自己负责的每个进行中项目都已填写下周参与人员和预计工时。
5. 已经彻底完成的项目已完成/归档。
6. 新增项目或初始导入项目的基本资料（包括项目阶段）没有待完善项。
