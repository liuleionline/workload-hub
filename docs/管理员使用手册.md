# 载衡系统管理员使用手册

## 首次上线

1. 使用命令行创建第一个系统管理员。
2. 登录后立即修改临时密码。
3. 在“员工与权限”中建立员工账号，初始密码可填写身份证号后6位。
4. 员工首次登录必须设置至少6位的新密码。
5. 在“系统设置”中检查每日标准工时、负荷阈值和连续超负荷报警规则。

## 员工和权限

- 业务层级包括部门领导、专业负责人和设计师。
- 系统管理员身份独立于业务层级，可由现有系统管理员增设。
- 新建或编辑账号时可标记为“测试用户”。测试用户按所选业务层级继承功能和权限，但不能同时设为系统管理员。
- 测试用户首次登录不强制修改初始密码；管理员重置测试用户密码后也不会触发强制改密。
- 测试用户本人仍可查看个人工时、看板和个人导出；其工时、请假、项目参与、负责人预测以及由测试用户创建的项目，不进入正式部门统计、排名、项目资源占用和部门总表。
- “个人权限”中的单独允许或禁止会覆盖角色默认权限。
- 停用账号会立即清除登录会话，但不会删除历史工时和项目记录。
- 所有权限、密码重置、项目状态和系统设置修改均写入审计日志。

## 项目

- 项目负责人/总设计师只是自由文本信息，可以填写公司其他员工姓名。
- “超大”项目最多设置两位专业负责人，其他项目设置一位。
- 执行专业负责人负责填写预估、维护并完成项目。
- 员工可以结束本人参与，只有有权的负责人或部门领导可以完成整个项目。

## 周填报

- 普通员工的填报窗口固定为每周五12:00至周六12:00；窗口内允许修改，窗口外禁止提交。
- 系统管理员为便于测试，可以随时新增、修改本人填报，也可以清空本人当前填报周期的实际工时和请假记录；这些操作均写入审计日志。
- 实际工时周期按相邻两次周填报截止点划分。
- “其它”工作计入全部负荷和统计，但不会带入下一周。
- 请假按0.5天填写，法定节假日与调休按工作日历自动处理。

## 备份

- 生产服务器计划在每周六18:00执行 `deploy/backup.sh`，生成数据库压缩包。
- VPS只滚动保留最近3份周备份；已启用的阿里云盘任务同步保留异地副本，系统不再弹出本地下载提醒。
- 进入“备份数据”可以查看服务器备份列表、文件大小、生成时间和当前管理员账号的下载状态。
- 下载、恢复和部门总表导出仅允许系统管理员执行，并会写入操作审计。每位系统管理员分别记录自己的下载状态。
- 下载后应将压缩包保存到VPS以外的电脑、NAS、移动硬盘或其它独立存储；建议本地也至少保留最近3份。
- 启用阿里云盘后，同一份周备份会在本地生成后自动上传；云端失败不影响VPS本地文件保留。
- “备份数据”页可上传 `.db` 或 `.db.gz` 恢复。系统会先校验数据库、创建恢复前保护备份，再恢复业务数据并强制所有账号重新登录。
