# 载衡员工使用手册

网址：请使用系统管理员提供的部署地址（示例：https://workload.example.com/）
登录账号：院邮箱
初始密码：身份证号后6位

## 每周实际工时

每周五12:00至周六12:00登录“工时填报”，记录上次周填报截止点至本次填报截止点之间的实际投入；窗口内允许反复修改。

* 从第二次填报开始，系统自动带入上周项目、工时和承担工作。
* 工时可以直接修改，也可以新增或删除项目。
* 第一次填写参与某项目时，必须详细填写工作内容，例如“xx子项”“xx子项设计（或校对/审核）”。当角色为设计时，应简要说明子项规模，例如“xx子项（15600平米混凝土框架结构）设计”。以后再次选择该项目时，系统会自动呈现最近一次工作内容；除非有新增或变化，无需重复填写。
* 发现自己项目（非临时任务）在项目池还没有时，提醒专业负责人添加项目。
* 临时任务、工地验收等选择“其它”，并填写具体内容。
* “其它”工作不会自动带入下一周。
* 如果本周后不再参与某项目，勾选“结束本人参与”。
* 有请假时按0.5天填写请假天数。

## 个人看板与报表

* 首页显示本周实际工时、可用工时、负荷率及八周趋势。
* 个人可以按月度、季度或年度查看参与和完成的项目，导出Excel、保存PDF或导出趋势图PNG。
* 原始工时由本人查看；偏差系数和修正负荷只对部门领导开放。

## 账号安全

* 初始密码只用于首次登录，首次登录后必须修改。
* 忘记密码时联系系统管理员重置。
* 不要把账号密码交给他人，也不要在公用电脑上保存密码。
